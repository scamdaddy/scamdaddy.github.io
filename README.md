# artemvib.github.io

личный сайт-портфолио Artem (@scamdaddy) в стиле неон/киберпанк.

🌐 **https://artemvib.github.io**

## что внутри

- звёздное небо на canvas: 3 слоя, параллакс от мыши и прокрутки, падающие звёзды
- приветствие, которое печатается само, и глитч-эффект на имени
- карточки проектов: QuestLog, Runaway, Forculus VPN и этот сайт
- мини-терминал: попробуй `help` или нажми `~` (на телефоне — кнопка `>_`)
- переключатель языка RU / EN, выбор запоминается
- бережёт слабые устройства и уважает настройку «уменьшить движение»

## технологии

чистый HTML, CSS и JavaScript — без фреймворков и без сборки.
GitHub Pages показывает сайт как есть.

## структура

```
index.html            разметка страницы
404.html              страница «улетела в космос»
css/style.css         все стили (цвета — переменные в начале файла)
js/i18n.js            все тексты на русском и английском
js/projects.js        проекты и ссылки
js/stars.js           звёздный фон
js/effects.js         печать текста, глитч, появление при прокрутке
js/terminal.js        мини-терминал
js/main.js            сборка страницы и переключение языка
assets/               иконки и картинка превью
tools/                исходник картинки превью и скрипт для картинок
```

## как запустить локально

просто открой `index.html` в браузере.

## как добавить проект

скопируй любой объект в массиве в `js/projects.js` и поменяй данные.

## как поменять картинку превью или иконку

поправь `tools/og-image.html` или `assets/favicon.svg`, потом выполни:

```
powershell -ExecutionPolicy Bypass -File tools\make-images.ps1
```

скрипт сделает новые PNG через Edge.
